# Community Channel Policy

Applies to Discord, GitHub Discussions, and the Hugging Face Community tabs of this project. The
[Code of Conduct](../../CODE_OF_CONDUCT.md) applies in all of them.

## Chat is not a record

Discord is for quick conversation. Chat never makes an official decision. Releases, data errors,
feature requests, and answers worth keeping are recorded on GitHub, as described in
[COMMUNITY.md](../../COMMUNITY.md#promotion-to-github).

## Allowed use

- Questions about using the dataset, and helping each other
- Discussing the public roadmap and open contribution work
- Event and release notices

## Forbidden use

- Discrimination, harassment, threats, or publishing someone's private information
- Spam, unsolicited promotion, or repeated unwanted direct messages
- Posting tokens, passwords, personal data, or undisclosed vulnerabilities
- Pressuring people for answers, or cross-posting the same question to several channels

## Actions

Moderators act in proportion to the severity and repetition of the behavior:

| Step | Action | Code of Conduct level |
|---|---|---|
| 1 | Notice: a private note asking for a correction | 1. Correction |
| 2 | Warning: a formal warning with consequences for repeat behavior | 2. Warning |
| 3 | Content restriction: messages hidden or removed, posting limited in a channel | 2. Warning |
| 4 | Temporary restriction: time-limited mute or ban | 3. Temporary Ban |
| 5 | Permanent ban | 4. Permanent Ban |

Severe cases (threats, doxxing, leaked credentials) can skip steps. Moderators follow
[MODERATOR_RUNBOOK.md](MODERATOR_RUNBOOK.md).

## Reporting

Report privately as described in [How to report](../../CODE_OF_CONDUCT.md#how-to-report). Only the
moderators and maintainers listed in [MAINTAINERS.md](../../MAINTAINERS.md) can see reports, and a
moderator with a conflict of interest steps aside.

## Appeals

You can appeal an action within **14 days** through the same private contact. A moderator who did not
take the original action reviews the appeal and replies with the outcome.
